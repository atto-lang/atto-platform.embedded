# Freestanding ownership and post-init no-allocation gates — draft 2026-10-18

Issue #19: embedded source/core must not secretly depend on OS/libc/GC services.

## Link and runtime proofs
- `core` builds with no Linux/POSIX, libc, global allocator, JVM, threads, clock, heap, I/O or standard library.
- `alloc` is opt-in and requires an explicit static arena/provider. `actor` is optional, uses injected bounded queue and scheduler, preserving trusted CONTROL priority.
- After initialization, freeze allowed arena budget and instrument allocations; interrupts, timer callbacks and actor turns must not call `malloc`, `free`, `new`, `sbrk` or tracing GC.
- Run the same binary in QEMU with bounded actor ticks; assert no host-only mocked output as substitute for actual MCU execution.
- Deterministic drops and lifetimes protect actor-owned data; mutable views cannot escape safe state loans.

## Negative vectors
1. Link source referencing `malloc` or POSIX socket: fail closed.
2. Tiny static arena, one extra message: bounded admission failure, no memory corruption.
3. CONTROL delivery at full DATA mailbox: actor remains supervisable.
4. Interrupt publishes after actor disposal: generation/owner check rejects.
5. Borrowed message outlives sending stack frame: static reject or safe moved copy.
6. Cyclic `Ref` misuse: reject without tracing collector.

**Status:** freestanding acceptance plan only. Needs actual linker map evidence, post-init allocation tracing and QEMU execution receipts.
